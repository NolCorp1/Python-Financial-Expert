Goal: Make backtest outputs deterministic (byte-for-byte stable given same args) AND ensure capital recycling actually triggers when intended, plus fix recycling comparison metrics (MaxDD% currently prints 0.00%).

Context / Observed Bugs
1) Non-determinism:
   - Same CLI args + same symbols list body => outputs/trades.csv, outputs/equity.csv, outputs/metrics.json hashes differ run-to-run.
   - User scrubbed volatile keys from metrics.json and still found drift:
       max_drawdown_abs 6072.65 vs 6072.66 (penny-level differences).
   - This indicates unstable ordering (set/dict iteration / tie sorts) and/or inconsistent rounding.

2) Recycling never triggers:
   - Even with extreme flags meant to force recycling:
       --recycle-trigger-mode ALWAYS
       --recycle-min-score-gap 0
       --recycle-min-hold-days 0
       --recycle-no-progress-days 0
       --recycle-no-progress-r 999
       --recycle-exclude-confirmed-winners false
     recycling_effectiveness shows recycle_events_count = 0 and comparison shows 0 recycling events.

   - Yet skip reasons show position pressure:
       “Max total positions”, “Max FORMING positions”, cluster caps, etc.
   - Likely recycler only triggers on budget_blocked and ignores position_blocked / cap_blocked.

3) Recycling comparison summary bug:
   - recycling_comparison_summary.csv shows max_drawdown_pct = 0 for all variants, even when main run prints non-zero drawdown.
   - Comparison runner likely reading wrong metric, wrong file, or defaulting to 0.

Implementation Requirements (Do not skip)
I) Deterministic Ordering Standard
Wherever signals/patterns/candidates/trades are iterated, enforce stable ordering:
- Must sort with a deterministic composite key that breaks ties uniquely.
- Recommended key chain (adapt to available fields):
  (date, signal_type_rank, -score, -score_per_risk, symbol, pattern_id_or_hash, entry_price_rounded)
- If pattern_id doesn’t exist, create one deterministically (hash of symbol + bottom dates + neckline date/price, etc.).

II) Deterministic Numeric Rounding
- Equity and PnL are dollar/cents concepts; pick a single rounding policy and enforce it:
  - Round equity to 2 decimals at each equity update step used for drawdown and output.
  - Round trade fills / proceeds to 2 decimals consistently.
- Ensure metrics.json drawdown fields use the rounded equity series so penny drift disappears.

III) Deterministic File Outputs
- CSV outputs must have deterministic row order:
  - trades.csv: sort by (entry_date, symbol, trade_id) before writing
  - equity.csv: sort by (date) before writing
  - report CSVs: sort keys consistently
- JSON outputs must use sorted keys and stable formatting (indentation consistent).
- Manifests can keep timestamps/run ids, but those must not affect the deterministic files above.
  - If metrics.json currently includes volatile fields, either:
    a) remove them, OR
    b) store volatile fields under a separate key AND exclude from deterministic hash tests (but Acceptance Tests require metrics.json itself deterministic, so prefer removal or stable values).

IV) Recycling Trigger Fix
- Ensure recycler can trigger on “blocked by caps” not just “blocked by budget”.
- Define “blocked” as:
  blocked = budget_blocked OR position_blocked OR cluster_blocked OR other_constraint_blocked
- If recycle_trigger_mode == ALWAYS:
  attempt recycling whenever there exist remaining candidates that were rejected for any constraint.
- If recycle_trigger_mode == BUDGET_BLOCKED:
  only attempt when budget_blocked is true (current behavior likely).
- When a recycling action occurs (PARTIAL or EXIT), record an event in a structured list so recycling_effectiveness is non-empty.

V) Recycling Comparison Runner Fix
- Ensure each variant run:
  - runs the backtest with recycling ON/OFF as specified
  - writes variant-specific metrics/equity/trades to separate temp files or in-memory objects
- Then compute:
  - total_return_pct
  - max_drawdown_pct (from variant equity curve)
  - trades count
  - recycling_events count
  - avg_swap_edge_r
  - false_recycle_rate
- Never default max_drawdown_pct to 0; assert it’s computed.
