2) Improve Scoring: Add Trade-Count + Exposure Penalties
--------------------------------------------------------
Your prior issue: too few quality windows / trades.

Implement a composite score that rewards return but penalizes:
- too few trades
- too little exposure

Add function in optimize.py:

    def score_oos_composite(trades_df, equity_df, max_dd_limit, min_trades, min_exposure_days) -> float

Compute:
- eq = compute_equity_metrics(equity_df)
- tr = compute_trade_metrics(trades_df)

Hard fails:
- if trade_count < min_trades: return -inf
- if max_drawdown_pct < -max_dd_limit: return -inf

Soft penalties:
- trade_penalty = min(0, (trade_count - min_trades) / min_trades)   # clamp
- exposure_days = count days with any open position (estimate from trades or equity exposure column if exists)
- exposure_penalty if exposure_days < min_exposure_days

Score baseline:
- base = eq["total_return_pct"]

Final:
- score = base * (1 + 0.25*trade_penalty) - 0.50*abs(eq["max_drawdown_pct"])

(You can tune weights, but keep it simple v1.)

Add CLI args:
- --min-trades-test (default 20 portfolio-level trades per test window)
- --min-exposure-days-test (default 20 days per test window)
- --objective composite|total_return|sharpe|expectancy_r
