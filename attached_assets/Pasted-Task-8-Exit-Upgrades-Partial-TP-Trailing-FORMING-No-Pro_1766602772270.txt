Key Rule: NO LOOKAHEAD
----------------------
Any new management rule must use:
- prior day's state (mfe_r up to yesterday)
- today's OPEN for management exits/partial fills
- and today's OHLC for stop/target fills
Do NOT use today's HIGH to decide a management action that happens at today's OPEN.

-----------------------------------------

        tr = max(
          high-low,
          abs(high-prev_close),
          abs(low-prev_close)
        )
        atr = tr.rolling(length).mean()
        return atr

4) CONFIRMED Partial Take Profit (Required)
-------------------------------------------
Rule:
- Only for entry_kind == "CONFIRMED"
- Trigger when price reaches entry_price + confirmed_partial_tp_at_r * original_risk_per_share
- When triggered, sell confirmed_partial_tp_fraction of initial shares at the trigger level (gap-aware).

IMPORTANT no-lookahead implementation:
- Use prior day MFE to decide whether partial TP is eligible at today's open.
- Then execute partial at today's open IF open is beyond level, else allow intraday fill.

Implementation details:
- partial_tp_level = entry_price + confirmed_partial_tp_at_r * original_risk_per_share

Execution order each day for a position:
A) Update bars_held and use PREVIOUS DAY mfe_r for management decisions at open.
B) Evaluate partial TP fills using today’s OHLC:
   1) If Open >= partial_tp_level:
        fill_price = Open * (1 - exit_slippage)
        mark partial_tp_done True
   2) Else if High >= partial_tp_level:
        fill_price = partial_tp_level * (1 - exit_slippage)
        mark partial_tp_done True

Shares to sell:
- shares_to_sell = floor(shares_initial * confirmed_partial_tp_fraction)
- ensure at least 1 and less than shares_remaining
- shares_remaining -= shares_to_sell
- realized_pnl += (fill_price - entry_fill) * shares_to_sell - commission

After partial TP, you may (optional) move stop to entry (or entry + small buffer).
This is configurable:
- confirmed_move_stop_to_be_at_r already exists; keep it.


5) CONFIRMED Trailing Stop (Optional but Recommended)
-----------------------------------------------------
After trailing start condition is met, tighten stop daily (never loosen):

Trailing start condition:
- prior_mfe_r >= confirmed_trailing_start_r
OR partial_tp_done == True

Trailing stop formula (ATR-based):
- trail_stop_candidate = today_close - confirmed_trailing_atr_mult * ATR(today)
- stop_loss_current = max(stop_loss_current, trail_stop_candidate)

No-lookahead rule:
- Use yesterday’s close/ATR to set today’s stop at open.
Simpler safe approach:
- Compute trail_stop_candidate using PREVIOUS DAY close and ATR:
  trail_stop_candidate = close[t-1] - atr_mult * atr[t-1]
  Apply at start of day t.

Then apply normal stop/target checks for day t.

NOTE:
- For long positions, trailing stop should only ratchet upward.


6) FORMING No-Progress: Support TIGHTEN_STOP Mode (Recommended Test)
--------------------------------------------------------------------
You already have no-progress EXIT working.
Now make TIGHTEN_STOP a first-class alternative:

If entry_kind=="FORMING" and bars_held >= forming_no_progress_days and prior_mfe_r < forming_no_progress_r:
- If action == "EXIT": exit at today's open (existing behavior)
- If action == "TIGHTEN_STOP":
    new_stop = entry_price + forming_tighten_stop_to_r * (entry_price - original_stop_loss)
    stop_loss_current = max(stop_loss_current, new_stop)
    mark "tightened=True" so this happens only once
    exit_reason is still STOP/TARGET later, but record in position meta that it tightened.

Goal:
- Avoid cutting winners too early while still reducing drawdown risk.
