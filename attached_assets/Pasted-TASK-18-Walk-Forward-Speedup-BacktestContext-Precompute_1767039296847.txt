TASK 18 — Walk-Forward Speedup: BacktestContext Precompute + Corr/Cluster Cache (no behavior change)

GOAL
Reduce optimize.py runtime from ~8–9s per parameter combo to ~2–4s per combo by:
- Precomputing window-invariant backtest inputs once (ATR series, returns matrix, master date calendar, regime DF)
- Reusing them across all parameter combinations in that window
- Caching corr/cluster computation by cutoff date (first_signal_date) so repeated cutoffs don’t recompute

WHY THIS MATTERS
Your optimize loop calls run_scan_and_backtest() for every params combo.
run_scan_and_backtest() calls run_backtest(), and run_backtest() currently recomputes:
- ATR for every symbol
- returns_df (pct_change) for every symbol
- all_dates union calendar
- regime_df (QQQ/SPY indicators)
- corr/clusters (often)
…for every combo.
That’s the primary reason you’re stuck at ~8–9s/it and timing out mid-grid.

SCOPE (FILES)
- backtester.py (or backtester 2.py in your repo): add BacktestContext + builder + caching; update run_backtest() to accept ctx
- optimize.py: build ctx once per window for train/test and pass it into run_scan_and_backtest()
- (optional) main.py: when running --backtest-v2, build ctx once and pass to run_backtest() for consistency/clean design

3) Add a builder function (place above run_backtest):

def build_backtest_context(
    price_data_by_symbol: Dict[str, pd.DataFrame],
    cfg: BacktestConfig
) -> BacktestContext:
    # ATR precompute
    atr_by_symbol: Dict[str, pd.Series] = {}
    for sym, df in price_data_by_symbol.items():
        atr_by_symbol[sym] = compute_atr(df, cfg.atr_length)

    # Returns matrix precompute (used for corr/cluster caps)
    returns_df = compute_returns_matrix(price_data_by_symbol)

    # Master calendar precompute
    all_dates_set = set()
    for df in price_data_by_symbol.values():
        all_dates_set.update(df.index.tolist())
    all_dates = sorted(all_dates_set)

    # Regime DF precompute (if enabled + available)
    regime_df = None
    if cfg.use_regime_filter and cfg.regime_symbol in price_data_by_symbol:
        df_regime = price_data_by_symbol[cfg.regime_symbol]
        if len(df_regime) > 0:
            regime_df = compute_regime(df_regime, cfg)

    return BacktestContext(
        atr_by_symbol=atr_by_symbol,
        returns_df=returns_df,
        all_dates=all_dates,
        regime_df=regime_df
    )
