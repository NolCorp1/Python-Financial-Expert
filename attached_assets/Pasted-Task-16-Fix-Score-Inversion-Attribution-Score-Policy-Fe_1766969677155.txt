Task 16 — Fix Score Inversion (Attribution + Score Policy + Feature Modes)
==============================================================================
Objective
---------
Your current Pattern Quality Score is inverted on recent backtests:
high-score buckets underperform. The scoring pipeline is wired correctly,
so Task 16 focuses on diagnosing which features are driving inversion and
adding safe, no-lookahead calibration knobs.

We will:
1) Add feature attribution diagnostics (per-feature correlation + quintiles)
2) Add score_policy modes: RAW vs INVERT (fast inversion proof) vs CALIBRATED (optional)
3) Add feature modes to trend + breakout + volume scoring to correct likely directionality

-------------------------

- CONFIRMED breakout candle is allowed (entry is next open), but any “follow-through”
  after breakout day is NOT allowed in scoring.

4) Make Breakout Strength Less “Exhaustion Candle” Biased
------------------------------------------------------------------------------
In pattern_scoring.py adjust compute_breakout_strength_score():

Currently:
- body_pct / 0.03
- green multiplier

Upgrade (still no-lookahead):
- Add margin above neckline:
    margin_pct = (close - neckline) / neckline
- Add ATR normalization (ATR% on pre-breakout bars):
    atr_pct = ATR14 / close (computed up to breakout_idx-1)
- Strength score should not reward huge bodies during extreme ATR%
  Example formula (clipped):
    body_score = clamp(body_pct / 0.02, 0..1)
    margin_score = clamp(margin_pct / 0.01, 0..1)
    vol_penalty = clamp(atr_pct / 0.05, 0..1)
    breakout_score = (0.5*body_score + 0.5*margin_score) * (1 - 0.3*vol_penalty)
    if not green: breakout_score *= 0.7

Note:
- Pass neckline into compute_breakout_strength_score()
- Use ATR based only on bars BEFORE breakout day close (ATR window ends at breakout_idx-1)

Acceptance:
- Breakout strength remains in [0,1]
- Adds neckline margin component
- Adds mild ATR penalty to reduce “blow-off” candles

5) Make Volume Score More Robust (log transform + cap)
------------------------------------------------------------------------------
In pattern_scoring.py update CONFIRMED volume:

Currently:
  vol_score = clamp((vol_ratio - 1.0) / 1.0, 0, 1)

Upgrade:
- Use log transform to reduce extreme influence:
    vol_ratio = breakout_vol / vol_ma20
    vol_score = clamp((log(vol_ratio) - log(1.0)) / log(2.0), 0, 1)
- This maps vol_ratio=2 -> 1.0, vol_ratio=1 -> 0.0 smoothly

FORMING bottom volume can remain, but add cap:
- vol_ratio_bottoms = vol_bottom2 / vol_bottom1
- vol_ratio_bottoms = min(vol_ratio_bottoms, 2.0)

Acceptance:
- Volume score is less dominated by extreme spikes
