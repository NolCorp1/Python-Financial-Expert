TASK 19 — Score-Based Risk Scaling (Pattern Quality → Position Size)

Goal
Add an optional “score-based risk scaling” layer so higher-quality double-bottom patterns take larger size and low-quality patterns take smaller size — without adding lookahead. This leverages the Pattern Quality Scoring you already built (Task 15–17) to improve profitability + reduce tail risk.

Why this matters
Right now, once a signal passes filters, its position size is mostly determined by entry_kind (FORMING/CONFIRMED) + regime multipliers. But your own diagnostics show not all patterns are equal — score deciles behave differently. This task makes the system *capital allocate* based on that information.

High-level behavior
- Compute a score multiplier from pattern_score ∈ [0, 100]
- Apply it to the per-trade risk fraction BEFORE share sizing
- Clamp sizing so it can’t go crazy
- Keep everything deterministic + no-lookahead (score is computed pre-entry)

Default multiplier function (smooth + intuitive)
Let s = clamp(pattern_score / 100, 0, 1)
score_mult = score_risk_min_mult + (score_risk_max_mult - score_risk_min_mult) * (s ** score_risk_alpha)

Examples with defaults min=0.6, max=1.2, alpha=1.0:
- score 0  → 0.60x risk
- score 50 → 0.90x risk
- score 100→ 1.20x risk

B) Add helper function
Somewhere near other helpers (top-level), add:

def compute_score_risk_mult(
    pattern_score: float | None,
    alpha: float,
    min_mult: float,
    max_mult: float,
    missing_policy: str = "NEUTRAL",
) -> float:
    """
    Convert pattern_score [0,100] into a smooth risk multiplier in [min_mult, max_mult].
    No-lookahead safe: uses only pre-entry score.
    """
    if pattern_score is None:
        return 1.0 if missing_policy.upper() == "NEUTRAL" else float(min_mult)

    try:
        s = float(pattern_score)
    except Exception:
        return 1.0 if missing_policy.upper() == "NEUTRAL" else float(min_mult)

    s = max(0.0, min(100.0, s)) / 100.0
    shaped = s ** float(alpha)
    return float(min_mult) + (float(max_mult) - float(min_mult)) * shaped

                missing_policy=cfg.score_risk_missing_policy,
